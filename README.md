# PFO2 — Prompt Engineering con agentes de IA

Proyecto realizado para la Práctica Formativa Obligatoria 2 sobre prompt engineering y desarrollo asistido por agentes de IA.

## Demo

[Ver despliegue unificado](https://pfo-landing-page-eight.vercel.app/)

La portada permite acceder a:

1. El prompt utilizado.
2. La landing page generada con Codex.
3. La landing page generada con Claude Code.

## Objetivo

Crear una landing page profesional, accesible y responsive para el **Espacio Gamer de General Lagos**, un taller donde niños y adolescentes aprenden informática mediante videojuegos, desafíos interactivos y actividades cooperativas.

La propuesta comunica el valor educativo del juego para desarrollar pensamiento lógico, resolución de problemas, creatividad, comunicación, trabajo en equipo, tolerancia a la frustración y perseverancia.

## Agentes utilizados

- **Codex (OpenAI):** generación de una propuesta de landing page.
- **Claude Code:** generación de una segunda propuesta para comparar decisiones de diseño e implementación.

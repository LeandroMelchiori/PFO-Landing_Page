# Espacio Gamer General Lagos

Landing page estática para promocionar el taller educativo Espacio Gamer de General Lagos.

## Archivos principales

- `index.html`: estructura semántica de la landing.
- `styles.css`: diseño responsive, accesible y mobile-first.
- `script.js`: navegación móvil, estado del header y simulación del formulario.
- `assets/hero-espacio-gamer.png`: imagen bitmap generada para el hero.
- `assets/logo-espacio-gamer.svg`: logo oficial adjunto del Espacio Gamer.

## Uso

Abrir `index.html` en un navegador o servir la carpeta con un servidor estático local.
